# Pytorch-Practice

Deep learning practice in PyTorch, organized into two folders:
- `pytorch_official_docs/`: notebooks from the official PyTorch tutorials (tensors, datasets, transforms, building models, autograd, optimization, saving/loading)
- `cs231n/`: work on Stanford CS231n assignments 1–3 (k-NN, softmax, fully connected nets, batch normalization, dropout, CNNs, RNN/Transformer captioning, self-supervised learning, CLIP/DINO, DDPM)
